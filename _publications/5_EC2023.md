excerpt: "Shows that sublinear-communication secure computation for more than two parties does not require fully homomorphic encryption, via a new framework built from function secret sharing for N parties. Gives sublinear protocols for various function classes in the 3- and 5-party settings, from assumptions not known to imply FHE."
